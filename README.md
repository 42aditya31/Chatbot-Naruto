## 🌀 What is Naruto?
Naruto is not your ordinary chatbot. This AI-powered roast master analyzes chats and replies with **savage humor**—perfect for those who can handle some **serious attitude**. If you're looking for polite customer support, you're in the wrong place. 😏

## 🔥 Features
- **Sharp-Witted Replies** – Expect no sugarcoating, only brutal honesty.
- **AI-Generated Humor** – Uses **GPT-3.5 Turbo** to craft the sassiest responses.
- **Chat Analysis** – Understands conversation tone and adjusts roasts accordingly.
- **Savage Level Control** – Dial up or down the heat if things get *too* real.
- **Fun & Engaging** – Best used for fun, pranks, or keeping friends on their toes.

## 🛠 Tech Stack
- **Python** 🐍 – Core development
- **OpenAI API** 🤖 – AI-powered responses


## 🚀 Getting Started
### 1️⃣ Clone this repo:
```sh
git clone https://github.com/42aditya31/Chatbot-Naruto.git
cd Chatbot-Naruto
```

### 2️⃣ Install dependencies:
```sh
pip install -r requirements.txt
```

### 3️⃣ Set up your OpenAI API key:
```sh
export OPENAI_API_KEY='your_api_key_here'
```

### 4️⃣ Run the chatbot:
```sh
python chatbot.py
```
